# Branding

- `uniterm-logo.svg` is the logo mark. The app icon in `App/AppIcon.icon` is built from it. The icon's layers drop the
  background, glow, and bevel, and its N cut is flattened into the outline, because Icon Composer supplies the plate,
  highlights, and shadow itself.
- `uniterm-word.svg` is the wordmark on a transparent background, cropped to its bounds.
- `uniterm-card.svg` is the same wordmark centered on a 600 by 300 light card.
